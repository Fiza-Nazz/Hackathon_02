# AI Native Todo Engine (Full Stack)
Built by **Fiza Nazz**.

This Space serves as the integrated backend for Phases 1, 2, and 3.
- **Phase I**: CLI & Logic
- **Phase II**: FastAPI REST API + Neon DB
- **Phase III**: AI Agentic Chatbot (Integrated)
- **Phase IV**: OpenAI ChatKit Integration

## Features

- **AI-Powered Task Management**: Natural language processing for task creation and management
- **Real-time Dashboard**: Live updates of tasks with priority and category filters
- **Multi-Language Support**: English and Roman Urdu language support
- **Secure Authentication**: JWT-based authentication with Better Auth
- **Responsive Design**: Mobile-friendly glass-morphism UI
- **Task Operations**: Create, read, update, delete, and complete tasks
- **Conversation History**: Persistent chat history with the AI assistant
- **MCP Integration**: Model Context Protocol for AI tool integration
- **OpenAI ChatKit**: Enhanced chat interface with OpenAI's ChatKit component

## Deployment Details
- **Port**: 7860
- **SDK**: Docker
- **Backend**: FastAPI / Python 3.11
- **Frontend**: Next.js with OpenAI ChatKit
